# Contributing to K53 SA Open Source 🇿🇦

First off, thank you for taking the time to contribute! This project is an open-source, community-driven platform designed to help learner drivers across South Africa master their K53 theory tests for free, while serving as a live-updating hub for traffic rules and regulations.

Whether you want to fix a typo, transcribe notes from the K53 manual, update road rules when the Department of Transport changes them, or build out new HTML/CSS/JavaScript features, your contributions are welcome!

---

## 🛠️ How Can You Contribute?

### 1. Digitizing K53 Manual Content
Help us transcribe and structure content from the physical K53 manual into our Markdown pages or JSON data files (`data/` directory). This includes:
* Explaining road signs (Regulatory, Warning, Guidance, Markings).
* Breaking down rules of the road (Speed limits, right of way, following distances).
* Outlining vehicle controls (LMV, HMV, and Motorcycles).

### 2. Updating Regulatory Changes
South African traffic laws and rules update over time. If you notice a change or if the Department of Transport/NaTIS updates a regulation:
* Open an issue or submit a pull request with the updated rule.
* **Crucial:** Always provide the official reference or link back to the [NaTIS Official Portal](https://www.natis.gov.za/) or government gazette.

### 3. Code & Website Improvements (HTML, CSS, JavaScript)
* Improving mobile responsiveness for learners studying on their phones.
* Building out or enhancing the interactive JavaScript mock test engine (`assets/js/quiz.js`).
* Fixing broken links or layout bugs.

## 🚀 Step-by-Step Contribution Workflow

If you are new to Git and GitHub, follow these steps to make your first contribution:

1. **Fork the Repository**
   Click the **Fork** button in the top right corner of the [repository page](https://github.com/Joaquimdacosta1999/k53-sa-open-source). This creates a copy of the project under your own GitHub account.

2. **Clone Your Fork Locally**
   Open your terminal (or command prompt) and run the following command (replace `YourUsername` with your actual GitHub username):
   ```bash
   git clone [https://github.com/YourUsername/k53-sa-open-source.git](https://github.com/YourUsername/k53-sa-open-source.git)
   cd k53-sa-open-source
